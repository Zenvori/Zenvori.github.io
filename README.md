# Zenvori.github.io

Zenvori 的个人博客首页，使用原生 HTML / CSS / JavaScript 构建，无构建步骤，可直接部署到 GitHub Pages。

## 发布

1. 创建公开仓库 `Zenvori.github.io`。
2. 将本目录中的 `index.html`、`styles.css`、`script.js` 推送到默认分支。
3. 在仓库 Settings → Pages 中选择 GitHub Actions 或从默认分支部署。

## 个性化

- 在需要公开联系方式时，添加经过确认的邮箱或社交链接。
- 发布项目与文章后，替换状态文字并补上真实链接。
- 如果暂时不需要 Google Fonts，可删除 `styles.css` 顶部的 `@import`，页面会自动使用系统字体。
